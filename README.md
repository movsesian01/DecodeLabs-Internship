# DecodeLabs-Internship
This repository contains projects, tasks, and code developed during the **DecodeLabs Virtual Internship**.

## 🤖 Projects

### Rule-Based AI Chatbot (`chatbot.py`)
A Python-based interactive chatbot designed to process user prompts and deliver context-aware responses.

* **Key Features:**
  * **Input Sanitization:** Normalizes text input (case conversion and trimming) to ensure robust matching.
  * **Keyword Mapping:** Utilizes dictionary structures for reliable response mapping.
  * **Fallback Handling:** Gracefully responds to unrecognized or out-of-scope queries.
